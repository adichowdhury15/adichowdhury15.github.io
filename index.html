Project Work

SHEET 2 OF 4 — PROJECTS

Full-Scale PC Model

Jul 2025 — Current

An ongoing personal build modeling a full-scale PC case in SolidWorks. Every dimension is hand-measured with calipers rather than pulled from a spec sheet, so each panel has to be individually verified for fit. The back panel includes graphics card brackets, a power supply slot, an I/O plate, and dual fan mounts for 120mm and 140mm fans with venting. The front panel carries its own fan mounting pattern and attachment points for a plate still in progress. The top panel integrates USB and audio ports, a reset switch, and power button alongside overhead fan mounts — the most component-dense of the three.

SolidWorks GD&T Caliper Measurement Independent
PANELS MODELED: BACK / FRONT / TOP STATUS: IN PROGRESS

Environmental Sustainability Exhibit

Feb — May 2025

An interactive children's-museum exhibit teaching families about energy use and renewable power. Arduino-based sensing reads resistor-encoded 3D-printed buildings and drives real-time RGB LED and display feedback. The physical models were built to survive repeated handling by kids — durable, painted for clarity, and mounted on a three-point contact system engineered specifically to keep voltage detection reliable even with imprecise, hands-on interaction.

Arduino MATLAB 3D Printing Team Project
OUTPUT: RGB LED + DISPLAY FEEDBACK USERS: MUSEUM VISITORS

Assistive Projectile Launcher

Jan — Feb 2025

A one-handed orthotic built with a team to let people with mobility and motor-control limitations participate in a shooting-competition activity. Development ran through the full engineering design process — repeated prototyping, testing, and a maintained BOM — while holding to a client-set $10 budget, a 2.5 lb weight limit, and fixed size restrictions. The final device placed top three in the class design and shooting competition.

Design Process Rapid Prototyping Assistive Design Team Project
BUDGET: $10 · WEIGHT: 2.5 LB MAX RESULT: TOP 3 OF CLASS

University Registration System

2026 — Coursework

An independent software project outside my core mechanical work — a Python based course-registration system built for an intro to programming class. Students and courses are modeled with nested data structures, and the program enforces the constraints a real registrar would need: a 13-credit cap per student, no duplicate enrollment, and no registering into a full course. Each operation lives in its own function with input validation so bad inputs never crash the program, and a small test suite covering both successful and rejected registration paths.

Python Data Structures Input Validation Independent
LANGUAGE: PYTHON TESTED: 4 CORE CASES
